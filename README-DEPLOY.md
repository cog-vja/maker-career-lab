# メーカーキャリアラボ：2026-11-10 デザイン改修の配置手順

## ZIPの位置づけ

このZIPは**現在のGitHubリポジトリに上書き・追加するための差分更新パッケージ**です。企業データ、記事、画像、月次更新の既存ファイルはZIPに再同梱していません。ZIPだけを空の新規リポジトリに配置してもサイトは動作しません。

## GitHubでの配置（既存リポジトリに適用）

1. ZIPを展開します。
2. `mcl_revenue_layer.py`, `mcl_editorial_layer.py`, `mcl-editorial.css`, `mcl-editorial.js`, `DESIGN.md` を、すべて **GitHubリポジトリの直下** に置いてください。`articles/` フォルダには入れません。
3. `mcl_revenue_layer.py` と `DESIGN.md` は上書き、残る3ファイルは新規追加です。
4. Cloudflare側で現在使用している `python3 cloudflare-build.py` によるビルドが行われると、公開用 `dist/` のHTMLとCSSに新デザインが反映されます。
5. `cloudflare-build.py`、`.github/workflows/`、企業データ、記事原本、広告・計測コードは上書きしないでください。

- 企業比較：スマホでの結果表を2社並列に再配置（既存5指標・元データ・出典は保持）

## 切り戻し

GitHubの上記5ファイルを、このデプロイ前のコミット状態に戻してください。既存記事や企業データへの変更は不要です。`mcl_revenue_layer.py` の追加2行が外れることで新デザインの配信処理は停止します。
