# メーカーキャリアラボ v0.3

GitHub Pages `https://cog-vja.github.io/maker-career-lab/` 用。すべてのファイルはリポジトリ直下に配置します（フォルダ不要）。

## アップロード
1. ZIPを解凍して全ファイルをリポジトリ直下にアップロード。
2. GitHub Pagesを main / (root) に設定。
3. `index.html` と記事リンク、CSSを確認。
4. Search Consoleに `sitemap.xml` を登録。

## 公開後の要作業
- `contact.html` に実際に受信可能な連絡先を設定（現状は未設定）。
- `about.html` の運営者情報を実際に公開可能な内容で更新。
- 広告承認後、ASP規約に従い広告リンクとPR表記を設置。未承認リンクを作らない。
- GA4などの計測タグは未設置。導入後 `privacy.html` を更新。
- 企業の実数値は一次資料で年度・対象範囲を確認してから掲載。
- ページの日付・公式リンク・サービス情報は運用時に定期確認。
