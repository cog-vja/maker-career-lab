# メーカーキャリアラボ v0.1
静的サイト初期版：トップ、記事5本、運営方針、プライバシー、広告方針、問い合わせ、共通CSS。

## 公開前チェック
- 運営者情報と問い合わせ先を記載
- 実際の解析ツール・広告に合わせプライバシーポリシーを確定
- 公開URL決定後に sitemap.xml を生成し robots.txt に記載
- A8に副サイト登録し、タイズ・メーカーズジョブに申請
- 提携承認まで広告リンクは掲載しない
- Search Console/GA4を設定し動作検証
- 企業データを掲載する場合は公式出典・年度・単体/連結を併記

GitHub Pages のリポジトリ配下でも相対リンクで動く構成です。
