# メーカーキャリアラボ：企業比較ツール v1

GitHub Pages向け。ZIP内のファイルは**すべてルート直下**に配置します。

## 更新内容
- `company-check.html`：企業比較画面（現職・検討先）
- `company-compare.js`：計算・表示・示唆の処理
- `company-data.js`：企業データ。現時点では**架空のデモ2社のみ**
- `style.css`：スマートフォン向け比較画面CSS
- `index.html`：比較ツールへの導線
- `about.html`：ユーザー指定の運営者プロフィールを維持

## 重要：実在企業の自動検索は未実装
会社名だけで実在企業の財務情報が自動表示される機能はまだありません。
実在企業は、会社名と一次資料の数値を手入力して比較してください。
架空デモは説明用で、実在企業の評価に使わないでください。

## データ単位
売上高・営業利益・前期売上高・営業CF：億円。平均年間給与：万円。自己資本比率：%。
会社ごとに決算期、連結/単体、給与対象、出典URLを必ず確認してください。

## 次の開発
金融庁EDINETの公式API等からバックエンドでデータ取得・検証し、APIキーをGitHub Secretsで管理する。
静的ページ上で秘密のAPIキーを利用しない。利用規約とデータ再配布条件も確認する。

## 公開前
既存サイトと同じリポジトリ直下に全ファイルをアップロード。`company-check.html`を開き「架空2社で試す」で動作確認。
