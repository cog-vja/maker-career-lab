# AGENTS.md — Maker Career Lab engineering rules

## Mission and release gate

- Improve https://maker-career-lab.com/ only through reviewed pull requests.
- Work exclusively on a feature branch. Never merge, directly push to `main`, deploy to production, enable auto-merge, or run `wrangler deploy` without explicit owner approval.
- Never alter repository secrets, account permissions, advertising accounts, DNS or billing.
- Stop and report failures; never fabricate financial data or claim passing tests that were not run.

## Architecture and approved content

- Site source is in repository root and `articles/`. `dist/` is generated by `python3 cloudflare-build.py` and MUST NOT be committed.
- The published site uses Cloudflare Workers Static Assets with `wrangler.jsonc`, and the build is deployed from `main` via Cloudflare Builds.
- Comply with `DESIGN.md` including responsive widths 320, 375, 390 and 430px, accessible controls, and the compact home page.
- Preserve canonical URLs, robots/sitemap, redirects from legacy GitHub Pages and publication allowlists.

## Business-critical controls

- Do not edit `company-data.js`, `company-compare.js`, EDINET extraction logic, source notices, financial indicators or numeric calculations without dedicated source-verification PRs.
- Preserve A8 tracking links, ad disclosures, GA4 instrumentation, affiliate attribution, privacy safeguards and navigation.
- Never equate affiliate clicks with confirmed paid commissions.
- Do not include nonpublic GA4/Search Console reports, personal data, credentials or affiliate commission statements in public PRs, logs or generated static output.

## Verification before presenting a PR

1. `python3 -m unittest -v test_v325.py test_v326_monthly.py test_pipeline.py`
2. `python3 cloudflare-build.py`
3. `python3 tests/test_pdca_smoke.py`
4. Run `node --check` on published `analytics-events.js`, `company-data.js`, `company-compare.js` and `mcl-editorial.js`.
5. Include affected routes, change rationale, tests actually executed, visual screenshots if relevant, and a rollback plan.
6. Static tests do not prove actual GA4 event dispatch or mobile browser correctness; require real-browser checks when relevant.

Only the owner may merge and publish. Green CI is necessary but not sufficient for approval.
